## Descrição do projeto

O presente projeto consiste no desenvolvimento de uma aplicação de lista de tarefas utilizando HTML, CSS e JavaScript puro, contemplando a implementação dos principais recursos relacionados às Progressive Web Apps (PWA).

A proposta teve como objetivo desenvolver uma aplicação simples e funcional, permitindo o gerenciamento de tarefas e, simultaneamente, a aplicação prática de conceitos importantes, como instalação da aplicação, armazenamento local de dados e funcionamento offline.

## Funcionalidades implementadas

A aplicação desenvolvida apresenta as seguintes funcionalidades:

- adição de novas tarefas;
- marcação de tarefas concluídas;
- exclusão de tarefas;
- armazenamento local utilizando LocalStorage;
- instalação da aplicação no dispositivo;
- funcionamento offline após o primeiro acesso;
- cache de recursos;
- utilização de Service Worker.

## Tecnologias utilizadas

Durante o desenvolvimento foram utilizadas as seguintes tecnologias:

- HTML5;
- CSS3;
- JavaScript;
- LocalStorage;
- Progressive Web App (PWA).

## Implementação do Service Worker

O Service Worker foi implementado com a finalidade de possibilitar o armazenamento em cache dos recursos da aplicação, permitindo seu funcionamento mesmo na ausência de conexão com a internet.

Durante seu desenvolvimento foram contempladas as etapas de instalação, ativação e gerenciamento do cache, bem como a recuperação dos recursos armazenados localmente.

## Funcionamento offline

Após o primeiro carregamento da aplicação, os recursos principais permanecem armazenados localmente. Dessa forma, mesmo sem acesso à internet, o usuário continua podendo acessar e utilizar normalmente a lista de tarefas.
